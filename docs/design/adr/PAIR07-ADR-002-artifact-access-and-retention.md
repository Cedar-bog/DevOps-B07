# PAIR07-ADR-002：产物读取入口与保留策略

- 状态：Accepted
- 命名空间：`PAIR07-ADR-*` = A07 / B07 双方共同决策
- 日期：2026-09-22
- 关联任务：E2-B07-015（J1 + J2）
- 关联文档：`B07-ADR-0002-artifact-passing.md`
- 关联 ADR：`A07:ADR-003`（`pair07` 命名与 URI 格式）

## Context

双方已就 URI 形状达成一致：`artifact://<pair>/<job>/<file>`，E2 中 `pair` 段固定为 `pair07`（`A07:ADR-003`）。**但 URI 如何定位到实际文件仍未决定**——A07 的 `A07:ADR-003` 与 `artifact-uri.md` 明确把「共享目录 / HTTP 下载 / 对象存储」列为待确认项，B07 的 `B07-ADR-0002` 也只写到「解析入口由平台定义（下载接口或解析器），与 A07 协商确认」。

这个决定不是纯技术选型，它被已有的 ADR 约束着：

- `B07-ADR-0002` 的 Alternatives 已**否决「直连生产方原始存储」**，理由是「耦合对方基础设施与网络，无统一解析入口，破坏可追溯性；E12 需要的是平台统一的读取证明」。**共享目录本质是该方案的变体**，选它会与已 Accepted 的 ADR 自相矛盾。
- 同一份 Alternatives 也已否决**内容寻址存储（CAS）**，理由是「超出 E2 课程规模」；`sha256` 字段已覆盖完整性校验需求。

因此三条候选路径中，只有 HTTP 入口与现有 ADR 一致且不引入额外基础设施。

保留策略（谁清理、留多久、谁能读）此前完全未讨论，但它与读取入口强耦合：读取入口若收归平台，清理权与引用可见性也自然收归平台。

## Decision

### J1 · 读取入口

**以 HTTP 读取入口为唯一主入口，共享目录只作为可选降级实现。**

```
GET /v1/artifacts/{pair}/{job}/{file}
  200 OK   Content-Type: <media_type>
           X-Artifact-Sha256: <sha256>
           body: 字节流
  404      未找到，或已过保留期
  403      跨 pair 访问
```

`X-Artifact-Sha256` 与 `$defs/artifact.sha256` 同源，供消费方下载后核验完整性（字段可选，跨组传递时推荐启用）。

E2 阶段只约定**接口形状**，不要求部署服务端，现阶段零成本；服务端落地在 E12。

### J2 · 保留、清理与权限

- **清理方 = 平台统一 GC**，不由生产方各自清理。
- **保留期 = 终态（`SUCCEEDED`/`FAILED`/`TIMED_OUT`/`CANCELLED`）后 30 天**。天数是为覆盖「检测 → 修复」跨多天的课程节奏，可再谈。
- **权限 = pair 内只读互访**：A07 写 B07 读、B07 写 A07 读，对称且最小。
- **硬约束（不变式）**：

  > 只要还有 Job 引用某个 artifact，该文件不得删除。

  此约束与 J1 一并落地，是实现层面必须保证的，而非最优努力。

## Alternatives

- **共享目录**：实现简单、无需服务端。但它是 `B07-ADR-0002` 已否决的「直连生产方原始存储」的变体——无统一入口、耦合对方文件系统与主机可达性、无 403/404 语义、保留与权限无法集中执行，且会破坏上述硬约束（生产方删目录时无人可见引用方是否还在用）。**若采纳，须回头修订 `B07-ADR-0002` 的 Alternatives，双方都要改。**
- **对象存储（S3 式）预签名 URL**：工业界标准做法，权限与保留天然可集中。但需要真实的对象存储与凭证体系，超出 E2 课程规模；可视为 HTTP 入口在 E12 之后的一种后端实现，不改变本 ADR 约定的形状。
- **生产方各自清理**：省掉集中 GC。但必然产生「引用还在、文件已删」的悬空引用，而 `artifact://` 的全部价值建立在引用可解析之上，因此被否决。
- **权限取全局可读**：省掉 pair 校验。但契约本身就是配对组之间的交接，读权限放大到全局既无必要、又扩大了泄漏面。

## Consequences

### 正面

- 与 `B07-ADR-0002` 的 Alternatives 自洽，不产生「Accepted 的 ADR 与其 Decision 互相打架」。
- 统一入口使**引用方与被引用方同时可见**，这是唯一能保证「有引用则不删」不变式的安排。
- 403/404 有明确语义：404 覆盖「未找到」与「已过保留期」两种情况，消费方据此区分「产物从未存在」与「过期回收」。
- 权限最小化（pair 内互读），与交接契约的边界一致。

### 代价与待办

- **需要一个服务端**。E2 不要求部署，只约定形状；E12 再落地。
- 保留期需平台 GC 维护引用计数或等价机制，才能保证硬约束；E12 设计存储时须一并考虑。
- 30 天保留期与「过期后 404」需在 `B07-ADR-0002` 的下游解析约定中体现为「下载失败的分支」。
